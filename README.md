---

## Sobre o Projeto

O projeto consiste em um **Portfólio Pessoal** desenvolvido do zero utilizando exclusivamente tecnologias nativas da web (*Vanilla Development*), sem a utilização de frameworks ou bibliotecas externas. 

---
## Objetivos de Aprendizado

O foco primário desse projeto foi aprimorar as seguintes habilidades:

* Seguir e cumprir estritamente todos os requisitos solicitados pelo professor.
* Organização de arquivos e diretórios do projeto.
* Estruturação semântica de páginas em HTML5, sem uso de frameworks (Bootstrap, Tailwind, etc.).
* Estilização responsiva com CSS3 puro, sem bibliotecas externas.
* Criação de um menu de navegação funcional, interligando as seções obrigatórias (Sobre mim, Formação, Portfólio e Contato).
* Manipulação do DOM com JavaScript puro (sem jQuery ou frameworks) para interações da página.
* Validação de formulário em JavaScript, verificando preenchimento de campos e formato de e-mail antes do envio.
* Simulação de envio de formulário com feedback visual ao usuário (mensagem de confirmação).
* Versionamento de código com Git/GitHub.
* Deploy e publicação de um projeto estático via GitHub Pages.
---

## Tecnologias Utilizadas

* **HTML5:** Estruturação semântica de conteúdo.
* **CSS3:** Estilização, componentes visuais e regras de responsividade.
* **JavaScript (ES6+):** Lógica de interação, manipulação do DOM e validação de formulários.
* **Git & GitHub:** Versionamento e hospedagem do código-fonte.
* **GitHub Pages:** Deploy e hospedagem pública da aplicação.

---

## Pré-requisitos

Por ser uma aplicação inteiramente frontend *Vanilla*, não é necessário instalar gerenciadores de pacotes (como `npm` ou `yarn`) ou ambientes de execução (como Node.js/Docker).

Será necessário apenas:
* Um navegador web moderno (Google Chrome, Mozilla Firefox, Edge ou Safari).
* Um leitor/editor de código (ex: [VS Code](https://code.visualstudio.com/)), caso queira visualizar os arquivos-fonte.
